# 🛒 Dynamic Dashboard for an Online Shopping Application

### 1. Project Title 

🛒 Dynamic Dashboard for an Online Shopping Application

An interactive Power BI dashboard designed to analyze sales performance, outlet performance, product categories, customer ratings, and inventory trends for an online shopping application.

---

### 2. Short Description

The Dynamic Dashboard for an Online Shopping Application is an interactive Power BI report designed to provide a clear view of key business performance metrics.

The dashboard focuses on analyzing sales performance, outlet analysis, product categories, customer ratings, and inventory trends. Interactive visualizations, KPIs, slicers, and filters help users explore the data and gain actionable business insights for better decision-making.

---

### 3. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 Power BI Desktop – Main platform used for dashboard development and data visualization.
- 🧹 Power Query – Used for data transformation and preparation.
- 🧮 DAX – Used for KPI calculations and analytical measures.
- 📈 Data Visualization – Used to represent sales, product, outlet, rating, and inventory trends.
- 🎛️ Slicers & Filters – Used for interactive data exploration and dynamic analysis.

---

### 4. Data Source

The dashboard uses an online shopping application dataset containing information related to:

- Sales performance
- Outlet information
- Product categories
- Customer ratings
- Inventory trends

The data was transformed and prepared using Power Query before being used for dashboard development and analysis.

---

### 5. Features / Highlights

The dashboard focuses on the following key areas:

- 💰 Sales Performance Analysis
- 🏪 Outlet Analysis
- 📦 Product Category Analysis
- ⭐ Customer Ratings Analysis
- 📊 Inventory Trend Analysis
- 🎯 Interactive KPI Cards
- 🔎 Dynamic Slicers and Filters
- 📈 Interactive Data Visualizations

#### Business Problem

Online shopping businesses generate large amounts of data across sales, products, outlets, customer ratings, and inventory. Without an interactive dashboard, it can be difficult to monitor performance and identify important trends efficiently.

#### Goal of the Dashboard

The goal of this dashboard is to provide an interactive and easy-to-understand view of business performance, allowing users to analyze different aspects of the online shopping application and support data-driven decision-making.

#### Key Visuals

The dashboard includes visualizations for:

- Sales Performance
- Outlet Performance
- Product Category Analysis
- Customer Ratings
- Inventory Trends
- KPI Metrics
- Interactive Filters and Slicers

#### Business Impact & Insights

The dashboard helps users:

- Monitor overall sales performance
- Compare outlet performance
- Analyze product category trends
- Understand customer rating patterns
- Monitor inventory-related trends
- Interactively explore business data
- Support data-driven business decisions
